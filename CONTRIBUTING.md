# Contributing to the NE-PGCoE Workflow Catalog

**Ownership:** Theiagen Genomics is building this catalog for the Northeast PGCoE under the Annotated Pipeline Inventory project. After the project ends, the catalog will be handed off to PGCoE, and this repository will be transferred to or copied into the PGCoE GitHub organization.

Current maintainer: Theiagen Genomics (until hand-off)
Maintainer after hand-off: PGCoE [name / team TBD]

## Adding a workflow

Pipeline developers submit workflow details through the **PGCoE contributor survey** [link TBD].
The maintainer reviews each response, adds it to the catalog sheet, and publishes an update (below).
Please don't open GitHub issues or pull requests to request new workflows or workflow edits.

## Updating the catalog (for the maintainer)

The catalog data lives in a Google Sheet, the master copy. This repository holds a CSV copy of each tab, and the website is built from those CSVs.

**1. Edit the sheet**
- Make changes on the **Catalog** tab, one row per workflow and organism. Select values from the dropdowns and the **Controlled Vocabularies** tab, and separate multiple values with `, `.
- New organism? Add it to the **Organisms** tab first, with its group, general-purpose flag and NCBI Taxonomy ID.
- Mark anything unconfirmed with `[verify]` and anything missing with `[to be completed]`. Cite sources as `[R#]` matching the **References** tab.

**2. Export**
- Open the **Catalog** tab, then **File → Download → Comma-separated values (.csv)**. Rename the file `catalog.csv`.
- Do the same for **Organisms**, **Controlled Vocabularies** (`vocabularies.csv`) and **References** only if they changed.
- If the sheet version changed, edit the version in `data/source.json`.

**3. Upload to GitHub**
- In this repository, open the `data` folder, then **Add file → Upload files**, and drag in the CSV files.
- Choose **Create a new branch… and start a pull request**.

**4. Check and publish**
- The **Validate catalog entries** check runs on the pull request. Open it and read the build report under **Summary**.
  - **Errors** must be fixed in the sheet, then re-export.
  - **Warnings** and remaining `[verify]` / `[to be completed]` counts are allowed in drafts.
- When the check passes, click **Merge**. The site rebuilds and republishes automatically within a few minutes.

Never edit `site/catalog.js`; it is generated by the build.
